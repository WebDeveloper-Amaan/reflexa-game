PROJECT OVERVIEW
================================================================================
A modern, interactive memory game where players must repeat increasingly 
complex color sequences. Built with React, TypeScript, and Tailwind CSS.

Game Concept:
- Computer shows a sequence of colored buttons lighting up
- Player must repeat the exact sequence by clicking buttons
- Each level adds one more color to the sequence
- Wrong input = Game Over
- Score increases with difficulty and level


TECHNOLOGY STACK
================================================================================
Frontend Framework:     React 19.2.3
Language:              TypeScript 5.9.3
Build Tool:            Vite 7.2.4
Styling:               Tailwind CSS 4.1.17
Audio:                 Web Audio API (built-in browser)
Storage:               LocalStorage API (built-in browser)
State Management:      React Hooks (useState, useCallback, useEffect)

GAME FLOW - FROM START TO END
================================================================================

PHASE 1: INITIAL LOAD
----------------------
1. User opens the application in browser
2. App.tsx component renders
3. useSimonGame hook initializes with default state:
   - gameState: 'idle'
   - level: 1
   - score: 0
   - sequence: []
   - difficulty: 'medium'
   - highScore: loaded from LocalStorage

4. UI displays:
   - Title: "SIMON SAYS"
   - 4 colored buttons (Green, Red, Yellow, Blue) in 2x2 grid
   - Center circle showing "🎵 SIMON"
   - Difficulty selector (Easy/Medium/Hard)
   - "Start Game" button
   - Scoreboard showing 0 score


PHASE 2: DIFFICULTY SELECTION
------------------------------
User can select difficulty before starting:

EASY:
- Sequence speed: 600ms between colors
- Score multiplier: 1x
- Best for beginners

MEDIUM (default):
- Sequence speed: 400ms between colors
- Score multiplier: 1.5x
- Balanced gameplay

HARD:
- Sequence speed: 250ms between colors
- Score multiplier: 2x
- For experienced players

Technical Implementation:
- User clicks difficulty button
- setDifficulty() function called
- State updates: difficulty = 'easy'|'medium'|'hard'
- Can only change when gameState is 'idle' or 'failed'


PHASE 3: GAME START
-------------------
User clicks "Start Game" button:

Step 1: startGame() function executes
   - Clears any existing timeouts
   - Resets game state:
     * level = 1
     * score = 0
     * streak = 0
     * playerSequence = []
   
Step 2: generateNext() creates first sequence
   - Generates random number 0-3 (represents color)
   - sequence = [2] (example: Yellow)

Step 3: showSequence() displays the pattern
   - gameState changes to 'showing'
   - Button lights up with glow effect
   - Plays musical tone via Web Audio API
   - Duration based on difficulty setting

Step 4: Wait for player
   - gameState changes to 'playing'
   - Player can now click buttons
   - Status shows "Your turn! 0/1"


PHASE 4: PLAYER INPUT
----------------------
Player clicks a colored button:

Step 1: handlePlayerInput() receives colorIndex
   - Plays button sound immediately
   - Adds color to playerSequence array

Step 2: Validation Logic
   
   SCENARIO A - CORRECT INPUT:
   ✓ Clicked color matches sequence[currentIndex]
   ✓ playerSequence = [2] (matches sequence [2])
   
   Check if sequence complete:
   - If playerSequence.length === sequence.length:
     → Player completed the level!
     → Go to PHASE 5 (Level Up)
   
   - If playerSequence.length < sequence.length:
     → Continue playing
     → Wait for next input
   
   SCENARIO B - WRONG INPUT:
   ✗ Clicked color doesn't match sequence[currentIndex]
   ✗ Example: Player clicked [1] but sequence was [2]
   
   Actions:
   1. Play fail sound (descending buzz)
   2. gameState changes to 'failed'
   3. Save game record to LocalStorage
   4. Update high score if beaten
   5. Show "Game Over" in center circle
   6. Button changes to "💀 Try Again"


PHASE 5: LEVEL UP
------------------
Player successfully completed the sequence:

Step 1: Calculate Score
   Formula: level × 10 × difficulty_multiplier
   
   Examples:
   - Level 3, Easy:   3 × 10 × 1.0 = 30 points
   - Level 3, Medium: 3 × 10 × 1.5 = 45 points
   - Level 3, Hard:   3 × 10 × 2.0 = 60 points

Step 2: Update State
   - score += calculated points
   - level += 1
   - streak += 1
   - gameState = 'levelUp'

Step 3: Visual Celebration
   - Play level-up sound (ascending notes)
   - Spawn 20 colored particles that animate outward
   - Center circle shows new level with yellow glow
   - Yellow glow ring around game board

Step 4: Generate Next Sequence
   - Add one more random color to sequence
   - Previous: [2]
   - New: [2, 0] (Yellow, then Green)
   - Wait 1.2 seconds

Step 5: Show New Sequence
   - Return to PHASE 3, Step 3
   - Display longer sequence
   - Player must remember more colors


PHASE 6: GAME OVER
-------------------
Player made a mistake:

Step 1: Save Game Data
   Data saved to LocalStorage:
   {
     score: 120,
     level: 4,
     date: "2024-01-15T10:30:00.000Z",
     streak: 3
   }

Step 2: Update High Score
   - Compare current score with stored highScore
   - If current > highScore:
     * Update highScore in state
     * Save to LocalStorage
     * Show "🏆 New High Score!" banner

Step 3: Display Results
   - Center circle shows "💀 GAME OVER"
   - Final score displayed in scoreboard
   - Button changes to "💀 Try Again"
   - Difficulty selector reappears

Step 4: View History (Optional)
   - Player can click "View History"
   - Shows last 10 games in a table
   - Displays: Rank, Score, Level, Date

Step 5: Restart
   - Player clicks "Try Again"
   - Returns to PHASE 3 (Game Start)

5. useSimonGame.ts - GAME LOGIC HOOK
-------------------------------------
Purpose: Core game state management and logic

State Interface (SimonGameState):
{
  sequence: number[]           // Pattern to repeat [0,2,1,3]
  playerSequence: number[]     // Player's inputs [0,2]
  gameState: GameState         // Current phase
  level: number                // Current level (1-∞)
  score: number                // Total points earned
  highScore: number            // Best score from storage
  activeButton: number | null  // Which button is lit (0-3)
  difficulty: Difficulty       // easy/medium/hard
  streak: number               // Consecutive levels
}

Key Functions:

A) generateNext(currentSequence)
   - Generates random number 0-3
   - Appends to existing sequence
   - Returns new sequence array
   - Example: [2] → [2, 0] → [2, 0, 3]

B) showSequence(sequence, difficulty)
   - Changes gameState to 'showing'
   - Loops through each color in sequence
   - For each color:
     * Wait (speed based on difficulty)
     * Light up button (set activeButton)
     * Play tone
     * Wait again
     * Turn off button
   - After all colors shown:
     * Change gameState to 'playing'
   - Uses setTimeout for timing
   - Stores timeouts in ref for cleanup

C) startGame()
   - Clears any existing timeouts
   - Resets all state to initial values
   - Generates first sequence (1 color)
   - Waits 500ms
   - Calls showSequence()

D) handlePlayerInput(colorIndex)
   - Only works if gameState = 'playing'
   - Plays button sound immediately
   - Adds colorIndex to playerSequence
   - Validates input:
     
     IF CORRECT:
       - Check if sequence complete
       - If complete:
         * Calculate score
         * Increment level
         * Increment streak
         * Change to 'levelUp'
         * Generate next sequence
         * Wait 1.2s
         * Show new sequence
       - If not complete:
         * Continue waiting for input
     
     IF WRONG:
       - Play fail sound
       - Save game record
       - Update high score
       - Change to 'failed'

E) setDifficulty(difficulty)
   - Only works if idle or failed
   - Updates difficulty in state
   - Affects:
     * Sequence display speed
     * Score multiplier

F) celebrateHighScore()
   - Plays success sound
   - Called when new high score achieved

Timeout Management:
- All timeouts stored in timeoutRef array
- clearTimeouts() clears all on cleanup
- Prevents memory leaks
- Prevents bugs from overlapping sequences


UTILITY SYSTEMS
================================================================================

1. sounds.ts - AUDIO GENERATION
--------------------------------
Uses Web Audio API to create sounds without audio files

Audio Context:
- Single AudioContext instance
- Lazy initialization (created on first use)
- Reused for all sounds

Musical Notes (Frequencies in Hz):
- Green (0):  329.63 Hz (E4 note)
- Red (1):    261.63 Hz (C4 note)
- Yellow (2): 220.00 Hz (A3 note)
- Blue (3):   164.81 Hz (E3 note)

Functions:

A) playTone(colorIndex, duration)
   - Creates oscillator (tone generator)
   - Creates gain node (volume control)
   - Sets frequency based on color
   - Fades out exponentially
   - Duration: 200-600ms based on difficulty
   - Volume: 0.4 (40%)
   - Waveform: Sine wave (pure tone)

B) playSuccessSound()
   - Plays 4 ascending notes
   - Notes: C5, E5, G5, C6
   - Timing: 120ms apart
   - Creates triumphant melody
   - Used for high score celebration

C) playFailSound()
   - Plays descending buzz
   - Starts at 150 Hz
   - Drops to 80 Hz
   - Duration: 500ms
   - Waveform: Sawtooth (harsh sound)
   - Indicates wrong input

D) playLevelUpSound()
   - Plays 3 ascending notes
   - Notes: A4, C#5, E5
   - Timing: 150ms apart
   - Waveform: Triangle (softer)
   - Celebratory sound

Error Handling:
- All functions wrapped in try-catch
- Silently fails if audio not supported
- Prevents crashes on older browsers


2. storage.ts - DATA PERSISTENCE
---------------------------------
Manages LocalStorage for saving game data

Data Structures:

GameRecord Interface:
{
  score: number      // Final score
  level: number      // Level reached
  date: string       // ISO date string
  streak: number     // Consecutive levels
}

Storage Keys:
- 'simon-says-records': Array of game records
- 'simon-says-highscore': Single high score number

Functions:

A) saveGameRecord(record)
   - Gets existing records
   - Adds new record to beginning
   - Keeps only last 20 records
   - Saves to localStorage
   - Updates high score if beaten
   - Wrapped in try-catch

B) getGameRecords()
   - Retrieves records from localStorage
   - Parses JSON string to array
   - Returns empty array if none exist
   - Returns empty array on error

C) getHighScore()
   - Retrieves high score from localStorage
   - Parses string to number
   - Returns 0 if none exists
   - Returns 0 on error

D) clearRecords()
   - Removes all saved data
   - Clears both records and high score
   - Used for reset functionality

Error Handling:
- Try-catch on all operations
- Handles localStorage not available
- Handles quota exceeded
- Handles JSON parse errors


3. cn.ts - TAILWIND UTILITY

Helper function for conditional class names

Purpose:
- Merge Tailwind classes

Uses:

Example:

→ "px-4 py-2 bg-blue-500"

2. SEQUENCE GENERATION
-----------------------

Random Number Generation:
- Uses Math.random()
- Range: 0 to 3 (inclusive)
- Each color has 25% probability
- No pattern or predictability

Sequence Growth:
Level 1: [2]                    (1 color)
Level 2: [2, 0]                 (2 colors)
Level 3: [2, 0, 1]              (3 colors)
Level 4: [2, 0, 1, 3]           (4 colors)
Level 5: [2, 0, 1, 3, 2]        (5 colors)
...and so on

Memory Challenge:
- Level 10: Remember 10 colors
- Level 20: Remember 20 colors
- Theoretical maximum: Unlimited


3. INPUT VALIDATION
-------------------

Validation Process:

Step 1: Player clicks button
   playerSequence = [2]
   sequence = [2, 0, 1]

Step 2: Check current position
   currentIndex = playerSequence.length - 1 = 0
   
Step 3: Compare values
   playerSequence[0] === sequence[0]
   2 === 2 ✓ CORRECT

Step 4: Check completion
   playerSequence.length === sequence.length
   1 === 3 ✗ NOT COMPLETE
   
   → Continue playing

Example of Wrong Input:
   playerSequence = [2, 1]
   sequence = [2, 0, 1]
   
   currentIndex = 1
   playerSequence[1] === sequence[1]
   1 === 0 ✗ WRONG
   
   → Game Over


4. STREAK SYSTEM
-----------------

Streak Definition:
- Number of consecutive levels completed
- Resets to 0 on game start
- Resets to 0 on wrong input
- Increments by 1 on level completion

Example Game:
Start: streak = 0
Level 1 complete: streak = 1
Level 2 complete: streak = 2
Level 3 complete: streak = 3
Level 4 failed: streak = 0 (saved as 3)

Streak is saved with game record for history

TROUBLESHOOTING
================================================================================

Common Issues:

1. Audio Not Playing
   - Check browser audio permissions
   - User must interact before audio plays
   - Some browsers block autoplay

2. LocalStorage Not Working
   - Check browser privacy settings
   - Incognito mode may block storage
   - Check storage quota

3. Buttons Not Responding
   - Check if gameState is 'playing'
   - Buttons disabled during 'showing'
   - Check console for errors

4. Sequence Too Fast
   - Adjust difficulty to Easy
   - Check DIFFICULTY_SPEEDS values
   - Increase timeout durations

5. Build Errors
   - Run: npm install
   - Check Node.js version (16+)
   - Clear node_modules and reinstall
